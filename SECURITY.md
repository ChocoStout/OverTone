# Security Policy

## Supported versions

The most recently released versions of the OverTone packages on NuGet receive security fixes.

| Package                                       | Supported          |
|-----------------------------------------------|--------------------|
| OverTone 1.0.x                                | :white_check_mark: |
| OverTone.Extensions.DependencyInjection 1.0.x | :white_check_mark: |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately through GitHub's
[private vulnerability reporting](https://github.com/ChocoStout/OverTone/security/advisories/new)
(the **Security → Report a vulnerability** button on the repository).

You can expect an initial response within a few days. Once a fix is available it will be
released to NuGet and disclosed in the [changelog](CHANGELOG.md).
